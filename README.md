# 🎫 Ticketfast - Sistema de Gestión de Tickets IT

Sistema completo de gestión de tickets de soporte técnico con control de inventario de hardware.

## Tecnologías

### Backend
- Node.js
- Express.js
- SQLite
- Nodemailer

### Frontend
- React
- Vite
- Recharts
- React Toastify

## Instalación

1. Clonar el repositorio
2. Instalar dependencias del backend: cd backend && npm install
3. Instalar dependencias del frontend: cd frontend && npm install
4. Configurar variables de entorno en ackend/.env
5. Iniciar: cd backend && npm run dev y cd frontend && npm run dev
